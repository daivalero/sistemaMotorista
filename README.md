# Sistema Motorista

Painel do motorista e da frota, feito primeiro para o celular e adaptado para tablet e computador.

## Como abrir

```bash
npm install
npm run dev
```

O app sobe em `http://localhost:5173`.

## Contas de demonstração

- Motorista: `motorista@rota.app` / `1234`
- Administrador: `admin@rota.app` / `1234`

## O que o app faz

- Motorista: ficar online, aceitar corridas, acompanhar ganhos e ver o perfil
- Admin: painel da frota, cadastro de motoristas, veículos e chamados

Os dados ficam salvos no navegador (`localStorage`).
